# Latte-Letters
This website is about a cafe named 'Latte & Letters' whose main motive is to get you all cozy and relaxed. Following this theme, I have created an interactive website using HTML, CSS and JavaScript.
This website features the menu of this homely cafe, which ranges from tea and coffee to cakes and pastries. In case you are unable to reach the cafe in-person, don't worry, we also have an online order tab that will deliver the taste of these delicacies straight to your home.
